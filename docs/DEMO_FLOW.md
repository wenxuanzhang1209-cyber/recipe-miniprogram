# 正式演示流程

> 版本：v1.0.0-rc.1 | 用途：产品演示、验收展示
> 演示环境不破坏生产数据（使用独立演示账号，数据可重置）

---

## 演示准备

```bash
# 1. 启动后端（SQLite 开发库）
cd server && DB_DIALECT=sqlite npm run dev

# 2. 微信开发者工具导入 client/ 目录
# 3. baseUrl 指向 http://localhost:3000/api/v1
# 4. 勾选「不校验合法域名」
```

**演示账号**：开发环境使用 Mock 登录（微信开发者工具中点击登录即可，code 自动为 `dev_` 前缀）。演示数据使用独立用户，不影响其他数据。

## 演示步骤（13 步，约 5 分钟）

| 步骤 | 操作 | 展示要点 | 预期效果 |
|------|------|----------|----------|
| 1 | 打开小程序 | 首页 | 轮播图 + 分类入口 + 今日推荐（带推荐理由）+ 热门榜单，骨架屏加载 |
| 2 | 点击「我的」→「微信一键登录」 | 微信登录 | 登录成功，显示昵称和「爱下厨的第 N 天」 |
| 3 | 返回首页，下拉刷新 | 下拉刷新 | 刷新动画，推荐更新 |
| 4 | 点击搜索框，输入「红烧」 | 搜索 | 防抖搜索，返回红烧类菜谱 |
| 5 | 切换到「菜谱」Tab，点筛选 | 筛选 | 选择菜系=川菜、难度、时长，结果实时过滤 |
| 6 | 打开任意菜谱详情 | 详情页 | 大图、食材清单、时间轴步骤、营养卡 |
| 7 | 调整用餐人数（2人→4人） | 人数换算 | 食材用量自动翻倍（如 300克→600克），"适量"不变 |
| 8 | 点击收藏 | 收藏 | 收藏成功提示，计数+1，再点取消 |
| 9 | 点击「开始做菜」 | 做菜模式 | 深色大字步骤、屏幕常亮、计时器、食材浮层 |
| 10 | 返回，点「我的」→ 浏览历史 | 浏览历史 | 刚才浏览的菜谱在列表中 |
| 11 | 点「饮食偏好设置」 | 偏好设置 | 设置忌口「香菜」、过敏原「海鲜」、菜系「川菜」，保存 |
| 12 | 返回首页 | 推荐变化 | 推荐倾向川菜，含海鲜/香菜的菜被排除，推荐理由更新 |
| 13 | 打开菜谱，点「分享给朋友」 | 分享 | 分享卡片显示菜名+封面 |

## 演示亮点话术

1. **个性化推荐**："设置偏好后，推荐会实时变化。比如设置了海鲜过敏，含海鲜的菜就永远不会推荐给你，而且每条推荐都告诉你为什么推荐它。"

2. **人数换算**："家里来客人，把 2 人份改成 6 人份，所有食材用量自动换算，'适量'这种没法换算的会保持原样。"

3. **做菜模式**："做饭时手上有油不方便划手机，做菜模式用大字号一步一步引导，屏幕不会息屏，需要计时的步骤自带计时器。"

4. **忌口提醒**："详情页会自动检查这道菜是否含你设置的过敏原，含的话会明确提醒。"
