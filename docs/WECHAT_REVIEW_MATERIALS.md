## 二、功能说明（审核备注用）

本小程序为菜谱查询工具，核心功能：

1. **菜谱浏览/搜索**：按菜系、口味、做法、难度、时长筛选，支持菜名/食材搜索
2. **菜谱详情**：食材清单、分步做法、营养信息（估算）、小贴士
3. **收藏与历史**：微信登录后收藏菜谱、查看浏览记录
4. **饮食偏好**：设置忌口、过敏原、辣度等，获得个性化推荐
5. **做菜模式**：大字分步引导、计时提醒

**测试路径**（供审核员使用）：
1. 打开小程序 → 首页自动加载推荐（无需登录即可浏览）
2. 点击「我的」→「微信一键登录」（开发环境使用 Mock 登录）
3. 登录后 → 收藏任意菜谱 → 设置饮食偏好 → 返回首页查看推荐变化
4. 打开任意菜谱详情 → 进入「开始做菜」体验做菜模式

## 六、审核注意事项

1. **类目资质**：菜谱类一般无需特殊资质，如选择「餐饮」类目可能需要食品相关资质，建议选择「生活服务-生活工具」或「工具-信息查询」
2. **内容安全**：菜谱内容为系统生成的家常菜，无敏感内容
3. **测试账号**：开发环境 Mock 登录（`dev_` 前缀），审核时需提供可用的测试环境
4. **营养数据**：已明确标注为估算值，不构成医疗建议
