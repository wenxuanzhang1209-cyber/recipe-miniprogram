# 用户使用手册

欢迎使用「家常菜谱」小程序！这里收录了 10000+ 道家常菜的详细做法。

## 1. 首页

- **顶部搜索栏**：点击进入搜索页
- **轮播大图**：当下最热门的菜谱，点击直达详情
- **菜系入口**：川菜、粤菜、湘菜等 8 大菜系一键直达
- **今日推荐**：根据你的浏览偏好个性化推荐（未登录时为热门随机）
- **热门榜单**：全站最受欢迎的菜谱
- 下拉可刷新全部内容

## 2. 找菜谱的三种方式

### 方式一：搜索
底部「菜谱」→ 顶部搜索，或首页搜索栏。支持：
- 按菜名搜：如"红烧肉"
- 按食材搜：如"鸡蛋"、"五花肉"，找到所有用到该食材的菜
- 搜索历史自动保存，热门搜索词一点即达

### 方式二：分类浏览
底部「分类」，四个维度任选：
- **菜系**：川/粤/鲁/苏/浙/闽/湘/徽/家常菜
- **口味**：麻辣、酸甜、清淡……
- **做法**：炒、炖、蒸、烤……
- **餐次**：早餐、午餐、晚餐、夜宵

### 方式三：全部菜谱
底部「菜谱」标签页：
- 顶部菜系快速切换
- 排序：最新 / 最热 / 收藏最多 / 最省时 / 最简单
- 右上角 ☰/▦ 切换列表和网格视图
- 右上角 ⚙︎ 打开筛选：按难度星级、烹饪时长过滤

## 3. 菜谱详情页

- **基本信息**：总时长、难度星级、份量、每份热量
- **食材清单**：买菜/备菜时逐项点击打勾，已备食材自动划线
- **制作步骤**：时间轴式分步图文教程
- **小贴士**：成功率翻倍的关键技巧
- **营养成分**：蛋白质、脂肪、碳水等六项数据
- **底部**：❤️ 收藏 ｜ 分享给微信好友

## 4. 登录与个人中心

底部「我的」：
- **登录**：点击「微信一键登录」即可，无需注册
- **我的收藏**：所有收藏的菜谱，随时回看
- **浏览历史**：看过的菜谱自动记录，支持一键清空
- **退出登录**：个人信息卡右侧「退出」按钮

> 未登录也可以浏览和搜索全部菜谱；收藏和历史同步需要登录。

## 5. 常见问题

**Q: 收藏的菜谱在哪里看？**
A: 底部「我的」→「我的收藏」标签。

**Q: 怎么取消收藏？**
A: 进入菜谱详情页，再次点击底部 ❤️ 即可取消。

**Q: 搜索历史怎么删除？**
A: 搜索页 → 搜索历史右侧 🗑 图标 → 确认清空。

**Q: 为什么推荐的菜谱变了？**
A: 推荐会根据你最近浏览的菜系口味自动调整，看得越多推得越准。
