## 一、服务说明

「家常菜谱」是一款提供家常菜菜谱查询、收藏、浏览和个性化推荐服务的微信小程序。您可以：

- 浏览、搜索 10,000+ 道家常菜菜谱
- 查看菜谱详情（食材、步骤、营养信息）
- 收藏菜谱、查看浏览历史
- 设置饮食偏好，获得个性化推荐
- 使用做菜模式（分步引导）

- **菜谱内容**：菜谱由系统基于中餐烹饪规律生成，仅供参考。烹饪结果受食材、火候、个人操作等因素影响，我们不保证成品效果。
- **营养数据**：营养成分为**估算值**（基于每100克食材营养数据推算），非精确检测值，**不构成医疗建议或精确营养指导**。如有特殊健康需求，请咨询专业医师或营养师。
- **食品安全**：涉及生食、未完全加热的肉类、过敏原等内容，请自行判断并确保食品安全。详情页会对您设置的过敏原作出提醒，但不能替代您自身的注意义务。
- **图片**：当前版本使用菜系示意占位图，后续将替换为真实菜品图片。
